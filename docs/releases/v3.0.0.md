## ⪩ Premiere Deck v3.0.0 ⪨

The panel inside Premiere Pro is laid out anew: one row per group of actions, a pinned row of your own choice at the top, automation switches inside the Files buttons, a scale slider, and one fixed layout that stays put however the panel is docked.

> The panel keeps its layout at 360 x 640 and centres itself when the panel is wider; use the scale slider in the footer (125 % is the setting for a 2K monitor). The former Auto copy and Auto sort switches now sit inside the SYNC and SORT buttons as an AUTO capsule; their stored values are kept.

---

### ⤷ Added ˎˊ˗

- **Pinned row** — up to five actions of your choice at the top of the Actions tab. Press the plus slot to edit: a press on any tile below pins or unpins it, the cross on a pinned tile removes it, the check ends editing. The row is kept by the app, so it survives a panel reinstall.
- **Scale slider** — in the panel's footer, 80 % to 150 % in steps of 5; the whole panel scales, the value is kept per computer, and a display at 125 % or more starts at 125 %.
- **Corner marks** — a tile with a choice shows a small mark in its corner: CLR's mark takes the current label colour and opens the colour menu, CUST's mark opens a size field.

### ⤷ Changed ˎˊ˗

- **Actions tab** — every group is one row with its code at the left edge (TIME, TRKS, SEL, CLIP, PROJ, SEQ, OUT, KEYS); tiles have one fixed size, icon over code, and the last tile of a row never stretches.
- **Files tab** — SORT carries the Auto sort capsule and SYNC the Auto copy capsule: the body of the tile runs the action, the capsule flips the automation; then USED, ZIP and SETUP, which checks and recreates the layout folders and bins once a project is set up.
- **Solo and Lock** — the whole tile is the switch; a lamp dot shows the on state.
- **Text sizes** — the panel uses the same type scale as the window (Sora, fixed roles), so both read alike.
- **Tooltips** — the full name and one line of what the action does, nothing else; the corner mark has its own tooltip with the current value.
- **Notices** — a result line hides after 3 s (10 s for a warning or error) and closes on a click; a line with a reason opens it on the first click.

### ⤷ Removed ˎˊ˗

- **Status line** — the "Watching" / "Paused" line of the Files tab.
- **Size field under the Sequence tiles** — replaced by the CUST corner mark.
