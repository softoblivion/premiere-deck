## ⪩ Premiere Deck v1.1.0 ⪨

The panel inside Premiere Pro now looks like the host window and groups its quick actions; the host window moves its settings into a sheet behind a gear in the title bar.

---

### ⤷ Added ˎˊ˗

- **Grouped quick actions** — the panel shows the quick actions as titled groups (Timeline, Selection, Clips, Tracks, Project, Sequence, Export) with the buttons in two columns and an action's format or preset control right above its button.
- **Panel design** — the panel inside Premiere Pro uses the host window's look: dark gradient, section cards with a status pill, pill buttons, capsule switches; it stays dark whatever Premiere's brightness setting is.

### ⤷ Changed ˎˊ˗

- **Settings sheet** — the host window's settings open from a gear in the title bar as a sheet over the current page (Premiere, Panel, Tools, Data, Behaviour, Appearance, Updates, About); the rail keeps Deck and the module pages only.
- **Module settings shown once** — the Files and AI search pages no longer repeat their settings below the page content; the Settings card at the end of a module page is the one place for them, and a change takes effect at once (model device, skipped bins, folder watching).
- **Fewer project scans** — a burst of Premiere events (an import of several files, a bin move) is read once after it settles instead of once per event.

### ⤷ Fixed ˎˊ˗

- **Launch with a project** — a project path with forward slashes was accepted by the host but ignored by Premiere Pro; the host now passes the path the way Premiere expects it.
