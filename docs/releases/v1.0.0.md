## ⪩ Premiere Deck v1.0.0 ⪨

First release: a Windows application plus a panel inside Adobe Premiere Pro that keeps project media sorted, turns routine timeline and project operations into single buttons, and finds frames in the footage by a text description with a model that runs locally.

> The panel is not code-signed yet. If it does not appear under Window > Extensions, open the Deck page or Settings > Panel in the host window and enable debug mode; the host writes the CEP `PlayerDebugMode` value after a confirmation and removes exactly what it wrote.

---

### ⤷ Added ˎˊ˗

- **Host application** — one portable `PremiereDeck.exe`: launches Premiere Pro with a project or without, shows the connection state, recent projects and an activity log, and keeps running in the tray while Premiere runs.
- **Panel that installs itself** — the host installs its CEP extension into the user's extensions folder on first start and replaces it whenever the host is updated; the panel connects to the host on its own, whichever side starts first.
- **Files: sorted media** — a layout of folders and bins (Footage, Audio, Graphics, Overlays, Motion, Exports, Project) created by one Setup; media imported from outside the project folder is copied into the layout, relinked to the copy and filed in the matching bin; files dropped into the layout on disk are imported into the matching bin; an item moved between bins moves its file.
- **Files: Collect, Pack, Undo** — Collect brings an existing project's external media into the layout with a plan to review first; Pack produces a project folder that opens elsewhere without offline media; every operation is journaled and the last one can be undone. Originals are never moved or deleted.
- **Quick actions** — 17 buttons in the panel: adjustment layer over the selection, remove all gaps, razor all tracks, delete empty tracks, select same source, select offline clips, set to frame size, colour labels by bin, solo audio track, lock other tracks, save version, consolidate duplicates, open project folder, reveal clip file, social copy (9:16, 1:1, 4:5), export frame, export sequence to Media Encoder.
- **AI search** — a local CLIP index of the project's footage (the model, 432 MB, is downloaded once when the module is enabled); a text query returns clips and times with a score bar; a hit opens in the Source Monitor at that time, is inserted at the playhead, or gets a marker. Nothing leaves the machine.
- **Self-update** — the host checks GitHub Releases, downloads and verifies the new exe, swaps it on restart and updates the panel with it; a failed update leaves the current exe untouched.
- **Portable data** — everything the app keeps lives in `premiere-deck_data\` next to the exe; per-project state travels in a hidden `.premiere-deck\` folder inside the project folder.
