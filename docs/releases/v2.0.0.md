## ⪩ Premiere Deck v2.0.0 ⪨

A new, smaller host window that grows when the panel connects, two crystal themes shared by the window and the panel, a panel built from icon tiles with inline results, and a Files module that sorts camera, stock and generated footage apart.

> The footage search module is gone, together with its model download. The `index` folder inside each project's `.premiere-deck` folder is no longer used and can be deleted by hand. The theme setting starts over at Crystal Black. The panel no longer opens by itself when Premiere Pro starts: open it once from **Window > Extensions > Premiere Deck** and Premiere keeps it in the workspace.

---

### ⤷ Added ˎˊ˗

- **Sort project** — one button in the Files tab files every media item inside the project folder into the layout folders and bins by content; every move is journaled and can be undone.
- **Sync all media / Sync used media** — copy media that lies outside the project folder into `Media` next to the project, all of it or only the files placed in sequences; no sorting, nothing deleted.
- **Make ZIP** — a visible button that packs the project folder into a `.zip` beside it after checking for offline media; it asks for a sync first while media is still outside the folder.
- **Stock and Generated folders** — video is told apart by camera tags and file names: camera footage goes to `Footage`, stock downloads to `Stock`, generated clips to `Generated`; a wrong guess is corrected by moving the item to another bin.
- **Audio classes** — music, voice and sound effects are recognised by a small audio model that runs on the processor in well under a second per file; file names and your own overrides still win.
- **Duplicate sequence** — a quick action that copies the active sequence as `name v2`, `v3`, ... and keeps the original active.
- **Inline results in the panel** — a pressed tile turns into a check or a cross for two seconds, the group keeps the last result line, and a failed line opens its one-line explanation on click.
- **Panel tooltips** — hovering a tile shows the full name and what it does in a card drawn by the panel, not a system tooltip.
- **Waiting screen** — while Premiere Pro runs without the panel, the window shows the menu path to open it and three buttons: check the panel update, check for app updates, reinstall the panel.
- **Reasons for copy failures** — the journal and the message say why a copy failed (access denied, file in use, disk full, path too long), and the project folder is checked for write access before the first copy.

### ⤷ Changed ˎˊ˗

- **Host window** — a 3:4 window with the Premiere-style glyph, the Launch button and the three most recent projects; when the panel connects it widens with a short animation and shows the Files and Actions tabs beside the Premiere status; it narrows back when the panel closes.
- **Themes** — Crystal Black (dark) and Crystal Sky (light) replace the four themes; the panel inside Premiere Pro follows the window's theme, and a switch redraws the window top to bottom.
- **Typeface** — Sora replaces Unbounded in the window and the panel.
- **Panel layout** — Files and Actions are tabs; quick actions are icon tiles in three columns inside collapsible groups; the format and preset choices sit on the tiles as small badges with a menu; the offline screen reads "Connecting to Host".
- **Files inside the project folder are moved, not copied** — Sort project and a bin move in Premiere move a file between layout folders (a rename on the same drive); files outside the project folder are still copied in and never touched.
- **Settings order** — Appearance first with the two theme cards, then Updates with the app and panel versions, Modules, Premiere, Tools, Data and About.
- **Quick actions in the window** — every action has an icon and a short label; the window keeps the visibility switches.
- **Panel reconnect** — a restarted app is rejoined by an open panel within a second; a panel update reloads an open panel as well.

### ⤷ Fixed ˎˊ˗

- **Stray panel window** — launching Premiere Pro from the app could leave a bare panel window in the corner of the screen that could not be moved or closed; the app no longer opens the panel by itself.
- **Mask files imported** — files in Premiere's `<project> Masks` folder were picked up by the folder watcher and listed as failed imports; the folder is now ignored and old entries are cleaned from the journal.
- **Double launch** — pressing Launch twice within a few seconds started Premiere Pro twice and showed an error.
- **Debug-mode offer flashing** — the offer to enable Premiere's extension debug mode no longer flickers while Premiere Pro exits.
- **Tray notice** — the "keeps running" notice shows once per run, not on every hide.

### ⤷ Removed ˎˊ˗

- **Footage search** — the local image-text index, its 432 MB model download, the Search page and its settings; the leftover model files are deleted from the app's data folder on the first start.
- **Remove all gaps** — replaced by Duplicate sequence.
- **Collect project / Pack for sharing** — replaced by Sort project, Sync all media, Sync used media and Make ZIP; the "Pack as zip" project setting is gone.
- **Dusk, Nova, Frost, Bloom** — replaced by the two crystal themes.
