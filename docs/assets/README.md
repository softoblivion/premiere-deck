The window screenshots are captured from the app running in its simulated mode (`--fake`, no Premiere Pro) at Scale
100 %: a capture at device scale 1.5 (the final size, no resize), reduced to 256 colours. The panel screenshots are
the real panel page served by `tests\panel\live_server.py --real-actions`, rendered in headless Chrome at
360 x 640 px and device scale 1.5, without a palette (a 256-colour palette drops the small mint status dot and lamps
and speckles the dark tiles). The development host's sample tab is hidden with `server.model["kinds"] = False`; the
lamp and colour state of the shot is set through its `/exec` endpoint (the LOCK lamp on with
`server.actions.toggles["lock_others"]`, the colour choice Rose with `set_choice(..., "label", "Rose")`). Each screenshot
exists in both themes; the README shows the Crystal Sky file by default and the Crystal Black file on a dark page.

The icon tiles under `sections\` and `icons\` are generated by `build\make_readme_svgs.py` from the application's
icon sprite and the Crystal Black colours of `src\premiere_deck\ui\themes.json`; they are never edited by hand. A
tile carries no text, so it needs no font and reads the same on light and dark pages.
