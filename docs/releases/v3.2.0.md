## ⪩ Premiere Deck v3.2.0 ⪨

One-click label and marker colours in the panel, a quick export of chosen audio tracks, and an update window whose Install button stays in reach.

---

### ⤷ Added ˎˊ˗

- **Labels row** — a new LBL row on the Actions tab with Premiere's 16 label colours and the 8 marker colours as one-click swatches. A label colour goes to the newest selection: the clips you selected last on the timeline (through Premiere's own Edit > Label menu) or the items you selected last in the Project panel, bins included. A small chip beside the tiles shows what a click will colour. With nothing selected nothing is coloured.
- **Live label names and colours** — the swatches follow Premiere's Preferences > Labels; when Premiere does not give them, the default names and colours are shown.
- **Marker colour (MRK)** — colours the markers at the playhead: sequence markers and the markers of the selected clips, a range marker included while the playhead is inside it. MRK repeats the last marker colour and can be pinned.
- **Audio tab** — exports the audio tracks you choose with one press: one switch per track of the active sequence, separate files or one mix, WAV 48 kHz 16-bit, MP3 or AIFF from Premiere's own presets, In to Out or the entire sequence. Files go to `Exports\Audio` in the project folder as `<sequence> - A2 Dialogue.wav`, never over an existing file. Track mutes are set for each file and restored afterwards, Stop ends the export after the current file, and a file that came out silent (a track soloed in Premiere) is reported.

### ⤷ Changed ˎˊ˗

- **Colour label (CLR)** — moved to the new Labels row with Colour labels by bin; it no longer opens a colour menu from its corner (the swatches replace it) and no longer colours the marker at the playhead (MRK does that).

### ⤷ Fixed ˎˊ˗

- **Update window** — with long release notes the Install button was pushed out of the window and could not be reached; the notes now scroll and Later and Install always stay visible. Long questions in the window's confirmation sheet scroll the same way.
