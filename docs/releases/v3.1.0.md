## ⪩ Premiere Deck v3.1.0 ⪨

Larger text and a taller title bar, so the window and the panel read comfortably on a large monitor at 100 % display scaling.

---

### ⤷ Changed ˎˊ˗

- **Text size** — every text style of the window and the panel is one step larger: body text 14 px instead of 13, labels, buttons and tile codes 13.5 / 12.5, headings 17, meta lines 12.5, paths and versions 13. Weights and line spacing stay the same.
- **Title bar** — 52 px instead of 44: a larger app glyph, the app name in the heading size, a taller version pill and larger Settings, Minimize and Close buttons.
- **Actions tab of the window** — a long action name wraps onto a second line instead of being cut off.
- **Panel lanes** — the group codes on the left (TIME, TRKS, PROJ, …) have a slightly wider column so the larger codes fit.
- **Settings > About** — the source code link reads `softoblivion/premiere-deck`.
