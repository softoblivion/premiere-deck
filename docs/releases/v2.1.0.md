## ⪩ Premiere Deck v2.1.0 ⪨

A denser panel with short codes on half-height tiles, switches for the automatic filing, track and colour buttons, sequence copies at 16:9, 9:16 or any size, an Export button and keyframe easing presets.

> Export with a preset is gone; the EXP tile opens Premiere's own Export mode for the active sequence. The Journal button has left the panel; the journal lives in the host window. Projects set up with 2.0 keep their automatic filing (both new switches start on); new projects start with both switches off.

---

### ⤷ Added ˎˊ˗

- **Auto copy and Auto sort** — two switches beside Set up project in the panel and the host window: Auto copy copies media imported from outside the project folder into `Media`; Auto sort files new media into the layout folders and bins. Both off: the app only watches.
- **Track buttons** — +V / +A add one video or audio track; −V / −A remove the outermost track when it is empty and unlocked.
- **Colour** — a CLR tile with Premiere's 16 label colours: colours the selected clips in the timeline (or the selected items and bins in the Project panel) and the marker at the playhead, and reports what it coloured.
- **Sequence copies** — 16:9 and 9:16 tiles make a reframed copy of the active sequence at that ratio with the frame size derived from the source; CUST takes any width x height.
- **Export** — the EXP tile opens Premiere's Export mode for the active sequence.
- **Keyframe easing** — SLOW, MED and FAST apply a bezier ease of growing strength to the keyframe pair around the playhead on every animated property of the selected clip; LIN sets the pair back to linear. Premiere's scripting exposes no bezier handles, so the ease is written as one keyframe per frame between the pair and LIN removes them.
- **Show activity** — the activity strip of the host window is behind a setting in Behaviour, off by default.

### ⤷ Changed ˎˊ˗

- **Panel tiles** — half the height, the icon beside a short code (ADJ, RZR, EMPT, +V, SRC, FIT, CLR, SAVE, DUP, EXP, FRM, ...), four columns; the full name and a one-line description stay in the tooltip.
- **Tabs** — Actions comes first and opens by default; the last tab is remembered.
- **Solo track and Lock others** — switches that show their state instead of two-step buttons.
- **Notices** — a result line under a group hides itself after 3 s (10 s for a warning or an error), and every notice, toast and result line in the panel and the host window closes on a click.
- **Make ZIP** — the archive is written into the project's `Exports` folder (the folder itself is left out of the archive) with its report beside it.
- **Host window Actions tab** — short names and icons for every action; the export presets row is gone.

### ⤷ Removed ˎˊ˗

- **Social copy** — replaced by the 16:9, 9:16 and CUST tiles.
- **Export sequence with a preset** — replaced by the EXP tile; the `presets` folder of the data directory is no longer used.
- **Journal tile in the panel** — the journal stays in the host window.
